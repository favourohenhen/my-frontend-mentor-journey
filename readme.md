# 🚀 My Frontend Mentor Journey

Welcome! This repository documents my hands-on journey solving challenges from [Frontend Mentor](https://www.frontendmentor.io/).

The goal of this repo is simple: build real-world web pages and components from design mockups, master mobile-first responsive layouts, and continuously improve my HTML, CSS, and JavaScript skills.

> 📌 **Status:** 20 projects completed so far — and more are being added as I continue learning!

---

## 🛠️ What I'm Learning & Using

- **HTML5**: Semantic tags, accessible structure, and `<picture>` elements for art direction.
- **CSS3**: CSS Grid, Flexbox, custom properties (variables), and mobile-first responsive design.
- **JavaScript**: DOM manipulation, interactive components (galleries, menus, counters), and event handling.

## 💻 How to View a Project Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/favourohenhen/my-frontend-mentor-journey.git
   ```
2. Navigate into the folder of the project you want to view:
   ```bash
   cd 01-qr-code-component
   ```
3. Open `index.html` in your browser, or run it with **Live Server** in VS Code.
